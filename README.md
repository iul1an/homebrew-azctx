# homebrew-azctx

Homebrew tap for [azctx](https://github.com/iul1an/azctx), a per-shell
isolated Azure subscription context switcher.

## Install

```sh
brew install iul1an/azctx/azctx
```

## Upgrade

```sh
brew update            # refresh the tap so it sees the latest release
brew upgrade azctx
```

To check the installed and available versions:

```sh
brew info azctx
```

## Notes

The cask in `Casks/` is generated by the azctx release pipeline on every
tagged release; do not edit it manually. Issues and pull requests belong
in the [main repo](https://github.com/iul1an/azctx).
